# Task

Predict the (cumulative) target `ConfirmedCases` AND `Fatalities` for each `ForecastId`. Your goal is to predict the global cumulative COVID-19 cases and fatalities to date.

# Metric

root_mean_squared_log_error

# Submission Format
```
ForecastId,ConfirmedCases,Fatalities
1,10,0
2,10,0
3,10,0
etc.
```

# Dataset

train.csv
```
Id,Province_State,Country_Region,Date,ConfirmedCases,Fatalities
1,,Afghanistan,2020-01-22,0.0,0.0
2,,Afghanistan,2020-01-23,0.0,0.0
3,,Afghanistan,2020-01-24,0.0,0.0
etc.
```

test.csv
