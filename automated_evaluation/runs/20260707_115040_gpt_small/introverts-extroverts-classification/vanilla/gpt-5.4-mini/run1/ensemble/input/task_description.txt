# Task

Predict the target `Personality` for each id. This task is about predicting whether a person is an Introvert or Extrovert, given their social behavior and personality traits.

# Metric

accuracy_score

# Submission Format
```
id,Personality
18524,Extrovert
18525,Introvert
18526,Introvert
etc.
```

# Dataset

train.csv
```

etc.
```
