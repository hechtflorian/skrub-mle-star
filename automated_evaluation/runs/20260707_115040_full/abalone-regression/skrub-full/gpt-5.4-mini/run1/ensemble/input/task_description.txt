# Task

Predict the target `Rings` for each `id` row. The goal of this competition is to predict the age of abalone from various physical measurements.

# Metric

root_mean_squared_log_error

# Submission Format
```
id,Rings
90615,10
90616,10
90617,10
etc.
```
