# Task

Predict the class value of the target `NObeyesdad` for each id row. This is multi-class classification task to predict obesity risk.

# Metric

accuracy_score

# Submission Format
```
id,NObeyesdad
20758,Normal_Weight
20759,Normal_Weight
20760,Normal_Weight
etc.
```
