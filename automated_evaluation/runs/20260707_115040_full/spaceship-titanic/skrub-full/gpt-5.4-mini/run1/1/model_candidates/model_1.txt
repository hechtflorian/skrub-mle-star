## Model name
CatBoostClassifier

## Example Python code
```python
import pandas as pd
from catboost import CatBoostClassifier
from sklearn.model_selection import train_test_split
from sklearn.metrics import accuracy_score

train = pd.read_csv('train.csv')
test = pd.read_csv('test.csv')

for df in [train, test]:
    df[['Deck','CabinNum','Side']] = df['Cabin'].fillna('X/0/X').str.split('/', expand=True)
    df[['FirstName','LastName']] = df['Name'].fillna('Unknown Unknown').str.split(' ', 1, expand=True)
    df['TotalSpending'] = df[['RoomService','FoodCourt','ShoppingMall','Spa','VRDeck']].fillna(0).sum(axis=1)

X = train.drop(columns=['Transported','Name','Cabin'])
y = train['Transported'].astype(int)
X_test = test.drop(columns=['Name','Cabin'])

cat_cols = ['PassengerId','HomePlanet','CryoSleep','Destination','VIP','Deck','Side','FirstName','LastName']
for c in cat_cols:
    X[c] = X[c].astype(str)
    X_test[c] = X_test[c].astype(str)

model = CatBoostClassifier(
    iterations=2000,
    depth=6,
    learning_rate=0.03,
    loss_function='Logloss',
    eval_metric='Accuracy',
    verbose=0,
    random_seed=42
)
model.fit(X, y, cat_features=cat_cols)
pred = model.predict(X_test).astype(bool).ravel()
sub = pd.DataFrame({'PassengerId': test['PassengerId'], 'Transported': pred})
sub.to_csv('submission.csv', index=False)
```
