# Task

Predict the continuous target `Calories` for each `id` row. Your goal is to predict how many calories were burned during a workout.

# Metric

root_mean_squared_log_error

# Submission Format
```
id,Calories
750000,93.2
750001,27.42
750002,103.8
etc.
```
