# Task

Predict the target `count` for each `datetime`. This task is about forecasting bike rental demand using historical usage patterns with weather data.

# Metric

root_mean_squared_log_error

# Submission Format
```
datetime,count
2011-01-20 00:00:00,0
2011-01-20 01:00:00,0
2011-01-20 02:00:00,0
etc.
```

# Dataset

train.csv
```
datetime,season,holiday,workingday,weather,temp,atemp,humidity,windspeed,casual,registered,count
2011-01-01 00:00:00,1,0,0,1,9.84,14.395,81,0,3,13,16
2011-01-01 01:00:00,1,0,0,1,9.02,13.635,80,0,8,32,40
2011-01-01 02:00:00,1,0,0,1,9.02,13.635,80,0,5,27,32
etc.
```
