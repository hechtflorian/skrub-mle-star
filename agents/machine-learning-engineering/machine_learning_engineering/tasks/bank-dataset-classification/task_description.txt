# Task

Predict the probability of the binary target `y` for each id. This task is about predicting whether a client will subscribe to a bank term deposit.

# Metric

roc_auc_score

# Submission Format
```
id,y
750000,0.5
750001,0.5
750002,0.5
etc.
```
