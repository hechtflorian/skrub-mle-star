## Model name
CatBoostRegressor

## Example Python code
```python
import pandas as pd
from catboost import CatBoostRegressor, Pool

# Load data
train = pd.read_csv('train.csv')
test = pd.read_csv('test.csv')

# Features and target
X = train.drop(columns=['median_house_value'])
y = train['median_house_value']

# CatBoost handles missing values and categorical features automatically (none here)
model = CatBoostRegressor(
    iterations=2000,
    depth=8,
    learning_rate=0.03,
    loss_function='RMSE',
    random_seed=42,
    verbose=False
)
model.fit(X, y, eval_set=Pool(X, y), use_best_model=True)

# Predict on the test set
preds = model.predict(test)

# Save submission
pd.DataFrame({'median_house_value': preds}).to_csv('submission.csv', index=False)
```
